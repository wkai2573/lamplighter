# 技術說明

《守燈人》是用 Three.js 在瀏覽器裡跑的 2.5D 橫向遊戲。所有模型、貼圖、音效與音樂都在執行時由程式產生，沒有任何外部素材檔。這份文件說明各系統怎麼運作、檔案在哪裡，給要修改或延伸這個專案的人看。

## 技術選型

| 項目 | 使用 | 說明 |
| --- | --- | --- |
| 3D 引擎 | Three.js 0.186 | WebGL2；使用 EffectComposer、UnrealBloomPass、OutputPass、Reflector 等官方擴充 |
| 打包 | esbuild | 開發模式 watch + serve（存檔自動重新整理）；正式版壓縮成單一 `app.js` |
| 聲音 | Web Audio API | 全部即時合成，沒有音檔 |
| 介面 | HTML + CSS | 疊在 canvas 上；字型為 Noto Serif TC 與 Cormorant Garamond（Google Fonts，離線時改用系統字型） |
| 測試 | Node.js + puppeteer-core | 操控系統內建的 Microsoft Edge 截圖；物理與關卡測試直接在 Node 執行 |

成品：約 7,200 行程式碼，`dist/` 只有 `index.html`、`app.js`（約 780 KB，含 Three.js）、`style.css` 三個檔案。

## 每一幀的流程

`Game.update(dt)` 依序執行：

1. 讀取輸入（含手把輪詢）
2. 天氣：閃電、陣風，算出風力
3. 玩家物理（3 個子步驟），並把事件（腳步、跳躍、落地、濺水、受傷、死亡、光爆）轉成音效與粒子
4. 大氣分區混合 → 霧、光照、天空的目標值
5. 石燈、互動提示、結局演出、吊橋木板、晶石
6. 主角動畫 → 取得提燈位置 → 更新提燈光源
7. 暗影 AI、巨影追逐、螢火收集
8. 旁白、提示、章節觸發；死亡與重生
9. 攝影機
10. 光源分配（燈光池、體積散射、粒子與水面的光源槽）
11. 粒子、雨、塵埃、薄霧、光柱、水面更新
12. 調色參數、套用大氣到引擎、混音、HUD

然後 `Engine.render()` 跑一次完整的後製流程。

## 渲染管線

```
場景 → HalfFloat RenderTarget（MSAA + depthTexture）
     → 體積散射 pass（讀顏色與深度）
     → UnrealBloom
     → OutputPass（ACES 色調映射 + sRGB）
     → 調色 pass → 畫面
```

**鏡頭與構圖**：透視攝影機，FOV 30°，距離角色 14.5～20.5 m（依區段），約 5° 俯角。窄視角讓畫面接近 2D 橫向構圖，但遠近物件仍有真實的視差與縱深。

**體積散射**（`render/post.js`）：對離鏡頭最近的 8 盞點光源，用深度貼圖還原每個像素的視線長度，沿視線對點光源的平方反比衰減做解析積分：

```
∫ ds / (h² + (s − t0)²) = (atan((d − t0)/h) − atan(−t0/h)) / h
```

`t0` 是光源在視線上的投影距離、`h` 是光源到視線的垂直距離、`d` 是到場景表面的距離。結果再乘上世界座標的 3D 雜訊，形成在雨霧中流動的光暈；被牆擋住的部分因為積分只算到表面，自然會被截斷。另外加一層月亮方向的前向散射。這個 pass 最後會把 NaN / Inf 清成 0，避免單一壞像素被 bloom 擴散成黑畫面。

**調色 pass**：色差、暗角、動態底片顆粒、飽和度與對比、陰影提亮、閃電白閃、受傷時邊緣泛紅、燈油不足或被巨影逼近時黑暗從畫面邊緣侵蝕、過場黑邊、淡入淡出。

## 光照

| 光源 | 類型 | 陰影 | 說明 |
| --- | --- | --- | --- |
| 月光（黎明時變成太陽） | DirectionalLight | 2048 px，跟著鏡頭焦點 ±26 m | 從場景後上方打來，物件有輪廓光、影子朝向鏡頭 |
| 天空光 | HemisphereLight | 無 | 依大氣分區改變顏色與強度 |
| 提燈 | PointLight，decay 1.35 | PCF 軟陰影 1024 px | 唯一投射點光源陰影的燈 |
| 火光池 | 4 盞 PointLight | 無 | 每幀指派給離玩家最近的石燈、營火、火盆、燈塔 |
| 光爆 | PointLight | 無 | 一瞬間的強光，快速衰減 |

燈光總數固定，只改強度。這樣材質不會因為燈光數量變動而重新編譯 shader。

**提燈**：掛在角色手上，用擺錘物理模擬（手的加速度會帶動擺盪、風會施加力矩），所以走路、跳躍時光影會晃。提燈的金屬框架也會投影，照出籠狀的影子。角色離燈只有幾十公分，物理衰減會讓斗篷過曝，所以角色的布料材質對亮部做了 highlight rolloff，並加了一道冷色的 Fresnel 輪廓光，讓角色在暗處也看得清楚。

**大氣分區**（`world/atmosphere.js`）：森林、深林、沉村、峽谷、洞窟、海崖、黎明共 7 組 preset，每組定義天頂與地平線色、雲色、霧色與密度、遠山顏色、月光強度與顏色、半球光、雨量、風、雷電頻率、體積散射強度、曝光、洞窟權重、薄霧量。區段交界 14 m 內平滑混合，數值再以指數阻尼追上目標，所以走進洞窟或淋到大雨都是漸變的。

## 天空、遠景與水面

- **天空**（`render/backdrop.js`）：跟著鏡頭移動的大球體 shader，包含漸層、會閃爍的星星、帶坑洞紋理的月亮與光暈、兩層 fBm 雲（被月光與閃電照亮）、黎明狀態（太陽與暖色雲）。
- **遠山**：四張大型平面，山脊線在 fragment shader 裡用 ridged noise 產生，自帶霧化與輪廓光；因為位置真的在遠處，視差是正確的。靠近海的那端山勢會降低。
- **水面**（`render/water.js`）：以 Three.js 的 `Reflector` 渲染倒影，再用自訂 shader 做 fBm 波紋法線、雨滴漣漪（網格化的擴散圓環）、Fresnel、對提燈與火光的鏡面高光、海面的月光（與日出）波光路徑，以及和場景一致的霧。只有玩家附近的水面會渲染倒影。

## 地形與碰撞

`world/level.js` 用折線定義每段地面，另外還有單向平台、實心障礙、水域、洞窟天花板等資料。`world/terrain.js` 把地面折線加上少量自然起伏，取樣成每 5 公分一筆的高度表。**碰撞與地形網格讀的是同一張表**，所以看到的地面就是踩到的地面。

地形網格以通道（z = 0）為中心，向後是緩坡、山丘或淹水谷地，向前緩降到鏡頭下方；缺口會延伸成峽谷或水域。依區段混合不同的地形形狀（森林、湖、洞窟、海崖），頂點色依坡度、高度與區段上色，再疊上程序化的地面貼圖（含會反射燈光的低粗糙度水窪）。洞窟另有天花板網格、山體外殼，以及玩家進入時會淡出的前景岩壁。

**玩家物理**（`game/player.js`、`game/collision.js`）：加減速、空中控制、coyote time、跳躍緩衝、可變跳躍高度（有最短上升時間）、從木板下跳、自動走上 0.32 m 以內的台階（平台與實心障礙都算）、涉水減速、深水溺斃、陣風推力、受擊擊退。每幀分 3 個子步驟整合，避免高速穿透。

## 程序化美術

- **貼圖**（`util/tex.js`）：以可平鋪的 value noise 與 Worley noise 產生地面、岩石、樹皮、木紋、屋瓦、磚牆、布料，每種都輸出 albedo、法線（由高度圖差分而來）與粗糙度。
- **植被**（`world/flora.js`）：松樹（沿彎曲樹幹堆疊的鋸齒圓錐）、枯樹（遞迴分枝）、海崖風吹松（平貼的葉團），共 13 種變體；以 InstancedMesh 每 60 m 分塊，只有靠近通道的樹投射陰影。草叢約一萬叢，也是 instanced。樹與草的風擺在 vertex shader 裡以世界座標計算，草還會被角色撥開。岩石是雜訊變形的二十面體，並改用盒狀投影 UV 避免接縫。
- **建築**（`world/structures.js`）：石燈籠（存檔點）、高腳屋（可站在屋脊上走）、木棧道、鳥居、吊橋（懸鏈線形狀、繩索、會斷的木板）、峽谷石柱、洞窟晶石與發光蘑菇（靠近提燈時會變亮）、燈塔（旋轉光束）。
- **主角**（`game/character.js`）：兜帽斗篷（LatheGeometry，破舊下擺，依速度與風擺動的 vertex shader）、無臉黑暗面孔與兩點微光眼睛、紅圍巾（10 節 Verlet 繩索，會避開身體）。走路、跳躍、落地下蹲、坐姿、跪下點燈、死亡倒下都是程序化動畫；轉身時會經過面向鏡頭的角度。

| 懸浮塵埃 | GPU 點精靈，只有被光照到才看得見 | 1,400 |
| 地面薄霧 | 貼地飄移的大型雜訊 billboard | 70 |
| 月光光柱 | 沿自身軸旋轉面向鏡頭的長條，森林、峽谷、洞窟 | 約 20 |
| 火花與餘燼 | CPU 粒子池，Additive 混合 | 2,500 |

**天氣**（`game/weather.js`）：依大氣分區的頻率觸發閃電（2～4 次閃光脈衝，同時照亮天空、雲、遠山、水面與月光陰影），雷聲依距離延遲 0.4～2.8 秒。吊橋與海崖有陣風循環（預兆、增強、持續、減弱），會把玩家往回推，雨絲、圍巾、斗篷、草與樹都跟著風變化。

## 遊戲系統

- **燈油**：同時是生命與資源。自然消耗（滿油撐 120 秒），高舉提燈消耗 ×3.2，光爆消耗 16%，被暗影打中扣 13%；螢火 +7%，點亮或靠近已點亮的石燈會補滿。燈油越少，照明半徑越小、畫面邊緣越暗、響起心跳聲。
- **石燈**：7 座，按 E 跪下點燈（火苗從提燈飛到石燈），同時是存檔點與暗影的安全區。
- **暗影**（`game/shadows.js`）：18 隻。狀態機為沉睡 → 升起 → 在光的邊緣徘徊 → 蓄力（眼睛發亮、尖嘯）→ 直線撲擊 → 退開。高舉提燈會逼退並慢慢燒掉牠們，光爆則一次清除範圍內全部。外觀是 billboard 上的 shader：扭曲雜訊構成的煙狀身體、內部紫色煙霧、只在面向光源那側燃燒的邊緣、溶解成灰燼的死亡效果。
- **晶石平台**：7 塊，只有在提燈照明範圍內才會實體化並發光，需要高舉提燈才過得去。
- **吊橋**：兩段共約 90 片木板，其中 8 片缺板、12 片爛木板，站上 0.42 秒就會斷裂掉落，重生時復原。
- **終章追逐**：巨影依與玩家的距離調整速度（6.5 / 5.0 / 4.2 / 3.6 m/s），直跑能維持約 7.7 m 的距離，停下約 2 秒就會被追上。
- **存檔**：localStorage 記錄最後點亮的石燈與統計資料，所有讀寫都包在 try/catch 裡（無痕模式也不會壞）。

## 聲音

```
各音源 → music / sfx / amb 匯流排 → master → lowpass（死亡與暫停時悶音）→ compressor → 輸出
          └→ 殘響送出 → 室外殘響（3.2 秒）/ 洞窟殘響（6.5 秒），依位置交叉淡化
```

殘響的 impulse response 是程式產生的衰減雜訊（越往後越暗）。

- **環境音**（`audio/ambience.js`）：低頻風與陣風呼嘯、遠近兩層雨聲、水聲、依週期起伏的海浪、洞窟空氣與滴水，以及隨機出現的蟋蟀、貓頭鷹、蛙鳴、火焰劈啪聲。
- **音效**（`audio/sfx.js`）：以濾波雜訊與振盪器組成。腳步會依地面材質（草、泥、石、木、屋頂、吊橋、涉水、晶石）改變；雷聲分成近距離的爆裂聲與低頻滾動；暗影的尖嘯是鋸齒波通過多個母音共振峰濾波器；連續收集螢火時音階會上升。
- **配樂**（`audio/music.js`）：
  - Karplus-Strong 撥弦演算法做出類似古箏的音色，演奏 D 小調五聲音階的隨機樂句
  - Pad 是兩個微微走音的鋸齒波加上高八度正弦波，經過緩慢移動的低通濾波
  - 低音持續音
  - 危險層：一組不協和的顫音和弦，隨暗影距離淡入
  - 共 9 種情緒（標題、森林、沉村、斷橋、洞窟、海崖、追逐、結局、靜音）；追逐戰加上合成太鼓與固定音型，結局轉為 D 大調
- 瀏覽器規定要等使用者第一次按鍵或點擊才能建立 AudioContext。

## 效能

- **畫質三段**：高、中、低，差別在解析度比例、MSAA、陰影解析度、反射解析度、Bloom 開關。遊戲中 FPS 連續 6 秒低於 38 會自動降一級。
- **Shader 暖機**：載入時先 `compileAsync`，再到 9 個代表場景各渲染一幀，把所有 shader 變體、陰影貼圖與反射目標都先準備好，遊戲中不會卡頓。
- **陰影成本**：只有提燈投射點光源陰影（立方體陰影要渲染 6 次）；遠處的樹不投影；植被以區塊分組讓視錐剔除有效。
- **水面反射**：只有玩家附近的水體會渲染反射。
- **實測**：本機 1080p 下每個場景都是 59～60 FPS（Edge，高畫質）。

## 已知限制
